## Posting notes
- **Sound:** all three are silent by design so you can drop any trending audio on top without
  fighting a voiceover. If you'd rather have VO, V1's script reads cleanly aloud in ~30s.
- **First frame matters** — TikTok/IG use it as the cover. V1 opens on the hook line, V3 opens
  on "500", both work as static covers.
- **Sequence for a launch week:** V1 (hook) → V2 (demo) → V3 (offer). Run V1 organically first;
  once it finds an audience, retarget viewers with V3.
- **Keep the seat count honest.** V1 and V3 both say "500 spots" without claiming how many are
  left. If you want live scarcity ("only 80 left"), say it in the caption where you can update
  it — not burned into the video.
