Format (per the Kiku system, by structure only — no reused footage). Each reel names the reference clip it
recreates; film that shot (same framing, expression, ~3 s) and render it in with `reels.html?r=<n>&clip=<your.mp4>`.
Branding: the stressed word in cream with a terracotta outline, the teardrop mascot sticker top-right.

0:00–0:03 reaction close-up, no talking, hook text on screen → HARD CUT at ~0:03 → real Skinstel screen
recording with its own overlay text → end ~0:11–0:13. Hook text: white, bold, black outline, centred over
the upper third (the reference reels sit it on or just above the face), one emoji, ≤ 14 words.

## Before filming (once)

- **Demo account:** Skintel+ (the conflict check is Skintel+ only). Notifications off, 9:41-style clean status
  bar if possible, light mode.
- **Demo shelf (real products, really scanned):** a retinol serum, a glycolic/AHA toner, a vitamin C serum,
  a gentle cleanser, a moisturiser, an SPF. Night routine: cleanser → glycolic toner → retinol serum →
  moisturiser. This is the setup the routine check is built to catch (it looks for retinol + AHA/BHA +
  vitamin C overlap).
- **Record each kit once, reuse it across reels** (Kiku re-used the same demo footage; only the hook changes).
- **Overlay rule:** overlays describe what the screen shows. If the app words a conflict differently, or finds
  none, change the overlay to match or don't post that cut. Never mock up a result.

### Demo kits (real screens, in order)

- **KIT A — Conflict check (Routine).** Routine tab → Tonight list with the 4 products → tap
  **Check for conflicts** → "Checking both routines…" → "**1 conflict to sort out**" with the warning drop →
  slow zoom on the card: "**Conflict:** …", the two product names joined with "+", and the fix line under it.
- **KIT B — Scan (Scanner → Verdict).** **+** → **Scan a product** → barcode in frame → product found →
  verdict screen (score ring, verdict chip, flag count) → scroll to **Why this verdict** rows.
- **KIT C — Ask.** Ask tab → type **@** → tag the retinol serum and the glycolic toner → send
  "Can I use these on the same night?" → answer writes out → scroll to the end of it.

   clearest payoff: the "1 conflict to sort out" screen pays the hook in one glance.
2. **Reel 3 (Competitor call-out, "google at 11pm")** — the #2 template, and the complaint is something
   every viewer has done, with no brand named. It also tests KIT C, so you learn whether Ask or the
   routine check holds attention better.
3. **Reel 2 (Friend POV)** — the #3 template; it's the only one shot mid-action rather than as a static
   reaction, so it tests a different first frame.

All three reuse KIT A or KIT C footage, so filming day 1 also covers most of the week.

## (b) Repost most: REGRET

It carried Kiku (103 of 420 posts and the single best reel). Rotate the number, the years and the object
("serums", "actives", "googling") and the reaction shot each time; keep the structure and the KIT A payoff.

## (c) Hooks I'm unsure about on the claims rule — flagged

- **Reel 7** ("how did you know not to use those two on the same night") presents the app's advice as
  something you can act on. Only post it if the recorded conflict card really names the two products and
  gives that fix. If the app phrases it as "use on alternate nights" or similar, keep that wording.
- **Reel 11** ("only read the front of the bottle") implies brands' front labels are misleading. It names
  no brand, but it's a mild jab at packaging in general; drop it if you'd rather not go there.
- **Reel 5** ("every serum the internet told me to") — fine on claims, but it points at influencer culture
  on the very platform you're posting to. Low risk, worth knowing.
- **Overlays "it found a clash" / "caught this one"** depend on the real result. The routine check is AI
  written per routine; if it finds nothing, the overlay would be false, so re-record or don't post.
- **Retinol + vitamin C** (your example) is a contested pairing; plenty of guidance says they can be used
  together with care. Let the app's own explanation do the talking and keep overlays to "it flagged them".
- **Not used anywhere, on purpose:** "find what's breaking you out" and any "clear skin" or "fixed my skin"
  line. Those read as a cause or result claim.
